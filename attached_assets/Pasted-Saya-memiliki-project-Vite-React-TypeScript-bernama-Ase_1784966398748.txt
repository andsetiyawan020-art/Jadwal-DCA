====================================================
FITUR BARU : AUTO DCA
====================================================

Buat modul baru bernama Auto DCA.

Fitur Auto DCA terdiri dari:

1. Membuat Jadwal Auto DCA
- Pilih Coin (BTC / ETH)
- Nominal pembelian (Rp)
- Tanggal mulai
- Jam eksekusi
- Frekuensi:
  - Harian
  - Mingguan
  - Bulanan
- Aktif / Nonaktif
- Edit jadwal
- Hapus jadwal

====================================================

2. Daftar Jadwal

Tampilkan seluruh jadwal Auto DCA.

Setiap kartu menampilkan:

- Coin
- Nominal
- Frekuensi
- Jadwal berikutnya
- Status Aktif / Nonaktif
- Tombol Edit
- Tombol Hapus

====================================================

3. Dashboard Auto DCA

Tambahkan ringkasan:

- Total Jadwal Aktif
- Total Nominal per Hari
- Total Nominal per Minggu
- Total Nominal per Bulan
- Jadwal Berikutnya

====================================================

4. Riwayat Auto DCA

Buat halaman riwayat.

Kolom:

- Waktu
- Coin
- Nominal
- Status

Status:

- SUCCESS
- FAILED
- CANCELLED
- SKIPPED

====================================================

5. Pengaturan Auto DCA

Halaman pengaturan berisi:

API KEY

Secret Key

Mode Auto DCA

Notifikasi

Auto Retry

====================================================

6. Guardrails

Tambahkan pengaturan:

- Total beli maksimal per hari (Rp)
- Maksimal pembelian satu transaksi (Rp)
- Jeda minimum antar transaksi (Menit)

Gunakan format ribuan otomatis saat mengetik.

Tetapi nilai yang disimpan harus tetap angka murni.

Contoh:

Tampilan:
10.000

Storage:
10000

====================================================

7. Validasi

Tidak boleh:

Nominal <= 0

Tanggal di masa lalu

Jam yang sudah lewat jika tanggal hari ini

Nominal melebihi Guardrails

====================================================

8. Local Storage

Untuk sementara semua data disimpan di Local Storage.

Buat service khusus.

Contoh:

AutoDcaStorage.ts

Jangan menyimpan langsung di Component.

hooks/

services/

types/

utils/
