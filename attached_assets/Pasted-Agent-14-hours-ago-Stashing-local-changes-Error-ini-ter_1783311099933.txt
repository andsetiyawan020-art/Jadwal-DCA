Error ini terjadi karena kamu pernah mengedit file Gradle tersebut secara manual di komputer lokal, lalu Git menolak meng-overwrite perubahan itu saat pull.

Karena versi GitHub sudah benar (entries filesystem/share sudah dihapus), cukup buang perubahan lokal dan pull ulang:

# Dari dalam folder: artifacts/btc-eth-tracker/android
# (atau dari mana pun di dalam repo BTC-ETH)
# Buang perubahan lokal di kedua file Gradle
git checkout -- artifacts/btc-eth-tracker/android/app/capacitor.build.gradle
git checkout -- artifacts/btc-eth-tracker/android/capacitor.settings.gradle
# Sekarang pull berjalan lancar
git pull origin main
Atau jika kamu ingin simpan perubahan lokal dulu (berjaga-jaga):

git stash
git pull origin main
git stash drop   # hapus stash karena sudah tidak diperlukan
Setelah pull berhasil, lanjutkan seperti biasa:

# Dari root BTC-ETH
npm install
# Masuk ke artifact
cd artifacts\btc-eth-tracker
npm run build
npx cap sync android
npx cap open android

Ubah format input mata uang Rupiah pada aplikasi BTC & ETH Tracker.

Yang diinginkan:

Kolom "JUMLAH BELI (IDR)"
Pengguna cukup mengetik angka tanpa titik, misalnya: 10000 1500000
Saat mengetik, otomatis diformat menjadi: 10.000 1.500.000
Nilai yang disimpan ke database tetap angka murni (10000, 1500000), bukan string yang mengandung titik.
Kolom "HARGA BELI PER KOIN (IDR)"
Jangan gunakan format desimal.
Perlakukan sebagai mata uang Rupiah.
Pengguna cukup mengetik angka tanpa titik: 1074991000
Otomatis tampil menjadi: 1.074.991.000
Nilai yang disimpan tetap angka murni tanpa pemisah ribuan.
Perhitungan aplikasi (Modal Bersih, Koin Diterima, DCA, Dashboard, Edit Transaksi, Riwayat, Export, Import) harus tetap menggunakan nilai numerik asli, bukan string yang sudah diformat.

Saat membuka transaksi lama untuk diedit, kedua input tetap tampil dengan format Rupiah (menggunakan titik sebagai pemisah ribuan).

Kolom JUMLAH BELI (IDR) dan HARGA BELI PER KOIN (IDR) harus mendukung paste.

Contoh:

Jika pengguna paste "1.074.991.000", nilai tetap tampil "1.074.991.000".
Jika pengguna paste "1074991000", otomatis berubah menjadi "1.074.991.000".
Jika pengguna mengetik angka satu per satu, format ribuan tetap muncul otomatis.
Sebelum disimpan atau dihitung, hapus semua titik sehingga nilai numeriknya menjadi 1074991000.
Gunakan Intl.NumberFormat('id-ID') atau formatter yang setara agar konsisten di seluruh aplikasi
